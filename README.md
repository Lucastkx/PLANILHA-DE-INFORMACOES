# PLANILHA-DE-INFORMACOES
Uma planilha desenvolvida com HTML, CSS e JavaScript, que permite visualizar e filtrar dados de forma rápida através de um sistema de busca dinâmico.

🚀 Funcionalidades

🔍 Busca em tempo real
📋 Exibição de dados em formato de tabela ( CARDS )
🎨 Interface simples e responsiva
⚡ Atualização dinâmica sem recarregar a página

📌 Objetivo

Este projeto foi desenvolvido para praticar manipulação de DOM e criação de interfaces interativas com JavaScript.

🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
